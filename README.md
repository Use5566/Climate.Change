# 學生 AI 自主學習平台

A/B/C 每段劃記最多 100 個 Unicode 字元，Unicode 標點與空白不計，英文字母與數字逐字元計算。相鄰或重疊範圍合併後仍須符合上限；超過時提示縮短，不自動截斷。前台與儲存端皆檢查，舊資料仍可讀取；若有超長舊劃記，需縮短後才能再儲存。

三組的摘要與推論頁攔截 copy、cut、dragstart、contextmenu 與 Ctrl/Cmd+C/X，頁面文字禁止選取，推論輸入框仍可選取以便編輯。返回閱讀／對話後恢復選取。本次只限制複製，不攔截貼上；無法防止截圖、OCR、系統取字或其他裝置取用。實體 iPad Safari 行為仍需教師實測。

身分確認：班級 601–605、座號 01–32、五位數字密碼，不收集姓名。

ABC 的立場問題一致：「如果政府為了改善氣候變遷及減少碳排放，要訂定規則限制學生在校使用冷氣的方式，你支持或反對呢？」下方列出限制每日開啟時間、使用溫度及使用月份三個例子。A/B 對話頁最前方固定顯示「請先說明一下你支持／反對的理由」，依學生立場替換。此為畫面引導，不呼叫 Gemini、不占提問額度、不加入保存的問答陣列，因此不改動舊劃記位置；重新登入仍可顯示。兩組 AI 提示亦包含核心議題與開場背景。

前台由 Python FastAPI 提供，後端透過指定服務帳戶核對私人 Google 試算表。C 組登入後進入「選擇立場 → 閱讀與劃記 → 摘要與推論」；A、B 組進入「選擇立場 → AI 對話與劃記 → 摘要與推論」。分組留白會顯示學習活動尚未開放。登入後網址統一為 /learn，舊分組網址會經權限檢查後轉址；學生頁面與錯誤提示不顯示 A/B/C 分組代碼。內部 API 與教師紀錄仍保留分組資訊，這是畫面隱藏，不是對開發者工具的保密。

A、B 共用聊天畫面與 Gemini 設定，分別讀取 prompts/interface_a.txt 與 prompts/interface_b.txt。教學方式以各組 TXT 的現行內容為準，教師可直接修改提示。Render 須設定 GEMINI_API_KEY 與 GEMINI_MODEL；程式不含真實金鑰，缺少設定時會提示尚未就緒。修改 prompt 後須依使用者授權更新 GitHub 並重新部署。公開 GitHub 上的 prompt 也是公開內容，勿放入私密資料。

設定 GEMINI_KNOWLEDGE_MODE=explicit，讓 A/B 各使用 prompts/science-knowledge.txt 的完整科學教材與專屬指令建立 Gemini Context caching。教材為已授權公開的 UTF-8 TXT，隨 GitHub 部署，不再從 private/ 或 Render Secret File 讀取。舊 GEMINI_KNOWLEDGE_PATH 的路徑值不再使用；先保留 explicit 模式，再移除該舊環境變數即可。預設 TTL 一小時，無人使用不自動續期；建立前檢查 token 容量，重新啟動會尋找同版本可重用快取。此教材可放 GitHub；學生對話不放共用快取，API 金鑰、憑證與密碼仍不得公開。修改教材後重新部署，內容雜湊會自動選用對應版本的快取；僅搬移檔案而未改內容時，可重用尚未到期的同版本快取。教材無法載入時不會退回無教材回答。設定與課前準備命令見 DEPLOY.md。

A、B、C 分別寫入同一份試算表原本的「A學習歷程」、「B學習歷程」、「C學習歷程」分頁。新版共 10 欄：紀錄時間、班級、座號、介面、立場、提交狀態、劃記原文、學生提問及AI回答內容、推論、對話總 tokens。移除學習紀錄的密碼與成績統計欄，登入名冊不變。A/B 保留完整問答，C 的問答欄留白、tokens 為 0。

對話總 tokens 加總已保存 AI 回覆的 usageMetadata.totalTokenCount，包含 API 回報的輸入、輸出及思考用量，快取 token 不另加一次。欄位為數字，可直接統計；若舊回答缺少 totalTokenCount 則顯示「資料不完整（已知 N）」，不將未知用量當成零。不包含未保存的失敗請求、共用快取建立或儲存費，不能直接當成帳單。既有 11 欄會在首次載入時與資料一併原子轉換，恢復備註移到 I 欄推論，原 K 欄清空。

介面 C 支援任意文字範圍劃記：選取文字後按劃記按鈕；再次選取已劃記範圍後按取消，可移除全部或部分劃記。摘要依文章順序列出選取原文。草稿自動儲存，提交後鎖定該學生的本篇紀錄。文章內容在 prompts/interface_c.txt，以 UTF-8 儲存，空白行分段，`# 主標題` 與 `## 小標題` 對應兩層標題，`**文字**` 可標示粗體；HTML 會顯示為文字。修改後須重新啟動本機服務；線上需依授權更新 GitHub 並完成 Render 部署，不需手動修改 Python。C 介面只有一篇固定文章，所有學生一律讀取 prompts/interface_c.txt，不依學生進度選用舊文章，也不自動產生文章版本。既有紀錄的文章備份只供紀錄使用，不作為畫面來源；舊雜湊識別碼僅保留儲存相容性。文章上限為 20,000 個 UTF-16 字元，完整紀錄另受 Google 單格容量限制；檔案空白、編碼錯誤或缺少時，C 新活動會顯示錯誤，A/B 與登入仍可使用。C 的 TXT 與 A/B prompts 一樣會隨程式公開至 GitHub，勿放入私密資料。

每位學生在所屬介面保留一列，第一次使用時排在資料末端，不按座號預留空白列；後續依班級、座號與介面更新原列。後端每 35 秒合併有變更的學生資料；無變更不寫入。前台短暫停止操作後將資料傳到後端記憶體暫存，畫面區分暫存與 Google 同步。最後提交立即同步，收到 Google 確認才顯示成功。一般批次超過約 1.5 MB 時拆成數個請求，失敗保留最新資料於下輪重試。

重新登入會恢復後端最新暫存；若服務曾重啟，則從 Google 最近成功同步的資料恢復。不需持久磁碟或 LEARNING_DB_PATH。正常連線下預期約 35 秒同步一次，網路故障可能延長未同步期間。必須使用單一 worker、單一服務實例；本次不宣稱已完成真實學生壓力測試。

A/B 重新登入會恢復已保存的完整問答、劃記、立場、階段與推論，提問次數由恢復的對話計算，不會因登出歸零。已以模擬 Google 儲存測試兩組的登出（含尚待同步）、關閉瀏覽器及服務重啟恢復，並確認恢復後的新提問帶入先前問答。尚未送到後端的操作無法保證恢復；服務重啟時以 Google 最近成功同步的資料為準。

記憶體回收：背景每 35 秒檢查一次，完整學生紀錄閒置滿 5 分鐘且已同步後清除；登出及提交成功也清除完整快取。未獲 Google 確認的內容繼續保留重試，清理不會主動丟棄未存進度。重新操作依既有列號讀回該學生單列，保留版本檢查；資料列遺失或學生不符會回報錯誤，不當作空白新紀錄。後端只長期保留列號、版本與儲存時間等小型索引，不再保留整班完整紀錄及完整已確認副本。背景也清除過期登入及限流計數。AI 回覆若存檔失敗，會在背景重試原回答，交由儲存端接手後才清除回答暫存，不重新呼叫 Gemini。Google 持續故障時，未存資料仍須佔用記憶體；這不等於保證 30 人同時使用的實際記憶體容量，仍需正式環境觀測。Python 可重用回收空間，作業系統顯示的記憶體不一定立即下降。

首次載入各介面時，合併「學習歷程」與先前「學習進度」中的最新版本，去除重複快照與空白列，寫回原本的「學習歷程」。合併與隱藏對應「學習進度」分頁在同一原子請求中執行，後者內容不刪除；不再建立進度分頁。若紀錄版本衝突或恢復備註損壞，停止合併並保留原資料。表格資料列統一 60 像素、文字靠上且裁切顯示，完整對話仍在儲存格與恢復備註中。

請勿在活動進行中直接排序、插入或刪除資料列，也勿移除 I 欄備註；分析時另製副本。每組每位學生保留本次活動一份最新資料，不保留中間版本；新活動須先規劃分頁與版本切換。教師可下載 Excel；CSV 不包含恢復用備註。原 SQLite 資料不會自動搬移。

V1 驗收前檢查（2026-09-20）：105 項 Python 測試及 39 項 JavaScript 斷言通過，涵蓋登入、ABC 儲存與恢復、10 次對話上限、100 字劃記、快取與記憶體清理。真實名冊有 156 位有效學生，A/B/C 各 52 位；601–604 各 31 位、605 為 32 位，四個缺號已由教師確認。156 位均以本機 API 通過登入驗證，正式試算表未寫入測試紀錄。尚待人工驗收真實 Gemini 回覆、線上寫入與恢復、實體 iPad 觸控及全班負載；不能以 healthz 成功視為 Google 或 Gemini 連線完成。

部署及名冊規格請見 [DEPLOY.md](DEPLOY.md)。登入名冊可維持支援的 4 欄或 11 欄格式，與目前 10 欄的學習歷程不同，名冊仍須保留密碼。

只提交程式碼至 GitHub。密碼表、private/、work/、JSON 憑證與 .env 不得提交。正式部署後不依賴本機 Excel 或 G 槽。

A/B 每位學生本次活動最多提問 10 次；同一題失敗重試不另計次數，第 10 題仍可重試取得回覆。達上限後可繼續劃記、寫推論並提交，前後端均限制新提問。舊版超過 10 次的紀錄仍可恢復與提交，但不能再提新問題。既有對話總字數及試算表容量保護仍有效，長篇對話可能提早達容量上限。每次 Gemini 請求依序帶入該學生的完整既有問答與當前問題，包含明確快取模式；共用快取只存教師教材與指令。此機制提供上下文，不保證 AI 一定正確理解指涉不明的問題。
