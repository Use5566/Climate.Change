# 學生 AI 自主學習平台

身分確認：班級 601–605、座號 01–32、五位數字密碼，不收集姓名。

前台由 Python FastAPI 提供，後端透過指定服務帳戶核對私人 Google 試算表。C 組登入後進入「選擇立場 → 閱讀與劃記 → 摘要與推論」；A、B 組進入「選擇立場 → AI 對話與劃記 → 摘要與推論」。分組留白會顯示尚未分配介面。

A、B 共用聊天畫面與 Gemini 設定，分別讀取 prompts/interface_a.txt 與 prompts/interface_b.txt。檔案內目前是可編輯的暫用教學提示。Render 須設定 GEMINI_API_KEY 與 GEMINI_MODEL；程式不含真實金鑰，缺少設定時會提示尚未就緒。修改 prompt 後須依使用者授權更新 GitHub 並重新部署。公開 GitHub 上的 prompt 也是公開內容，勿放入私密資料。

可設定 GEMINI_KNOWLEDGE_MODE=explicit 與私密 GEMINI_KNOWLEDGE_PATH，讓 A/B 各使用完整科學教材與專屬指令的 Gemini Context caching。預設 TTL 一小時，無人使用不自動續期；建立前檢查 token 容量，重新啟動會尋找同版本可重用快取。教材檔不放 GitHub，學生對話不放共用快取。教材無法載入時不會退回無教材回答。設定與課前準備命令見 DEPLOY.md。

A、B、C 分別寫入同一份試算表原本的「A學習歷程」、「B學習歷程」、「C學習歷程」分頁。ABC 均使用教師指定的 11 欄格式，A、B 保留完整問答，C 的問答欄留白。密碼與成績統計留白。

介面 C 支援任意文字範圍劃記：選取文字後按劃記按鈕；再次選取已劃記範圍後按取消，可移除全部或部分劃記。摘要依文章順序列出選取原文。草稿自動儲存，提交後鎖定該學生的本篇紀錄。文章內容在 backend/article.py，替換正式文章時須更換 ARTICLE_ID，避免既有劃記位置錯置。

每位學生在所屬介面保留一列，第一次使用時排在資料末端，不按座號預留空白列；後續依班級、座號與介面更新原列。後端每 35 秒合併有變更的學生資料；無變更不寫入。前台短暫停止操作後將資料傳到後端記憶體暫存，畫面區分暫存與 Google 同步。最後提交立即同步，收到 Google 確認才顯示成功。一般批次超過約 1.5 MB 時拆成數個請求，失敗保留最新資料於下輪重試。

重新登入會恢復後端最新暫存；若服務曾重啟，則從 Google 最近成功同步的資料恢復。不需持久磁碟或 LEARNING_DB_PATH。正常連線下預期約 35 秒同步一次，網路故障可能延長未同步期間。必須使用單一 worker、單一服務實例；本次不宣稱已完成真實學生壓力測試。

首次載入各介面時，合併「學習歷程」與先前「學習進度」中的最新版本，去除重複快照與空白列，寫回原本的「學習歷程」。合併與隱藏對應「學習進度」分頁在同一原子請求中執行，後者內容不刪除；不再建立進度分頁。若紀錄版本衝突或恢復備註損壞，停止合併並保留原資料。表格資料列統一 60 像素、文字靠上且裁切顯示，完整對話仍在儲存格與恢復備註中。

請勿在活動進行中直接排序、插入或刪除資料列，也勿移除 K 欄備註；分析時另製副本。每組每位學生保留本次活動一份最新資料，不保留中間版本；新活動須先規劃分頁與版本切換。教師可下載 Excel；CSV 不包含恢復用備註。原 SQLite 資料不會自動搬移。

介面 C 驗證：27 項 Python 測試、8 項文字範圍斷言通過；本機瀏覽器實測選取／取消、摘要、草稿刷新恢復及提交後刷新。已檢查 1024×768 排版，尚待實體 iPad Safari 觸控驗證。

部署及名冊規格請見 [DEPLOY.md](DEPLOY.md)。2026-09-12 已通過 16 項模擬測試，並以真實服務帳戶讀取指定線上試算表，確認 160 位學生資料有效。以本機 Python HTTP 服務實測 A、B、C 與未分配介面四種狀態的登入、session、錯誤密碼拒絕與登出，全部通過。未修改試算表，未部署 Render，不能以 healthz 成功視為 Google 連線完成。

只提交程式碼至 GitHub。密碼表、private/、work/、JSON 憑證與 .env 不得提交。正式部署後不依賴本機 Excel 或 G 槽。
