# 學生 AI 自主學習平台

身分確認：班級 601–605、座號 01–32、五位數字密碼，不收集姓名。

前台由 Python FastAPI 提供，後端透過指定服務帳戶唯讀連接私人 Google 試算表。C 組登入後進入「選擇立場 → 閱讀與劃記 → 摘要與推論」。A、B 組暫時顯示分組資訊，分組留白會顯示尚未分配介面。

介面 C 支援任意文字範圍劃記：選取文字後按劃記按鈕；再次選取已劃記範圍後按取消，可移除全部或部分劃記。摘要依文章順序列出選取原文。草稿自動儲存，提交後鎖定該學生的本篇紀錄。文章內容在 backend/article.py，替換正式文章時須更換 ARTICLE_ID，避免既有劃記位置錯置。

本機學習紀錄預設儲存在 private/learning.sqlite3，不包含密碼。Render 上的 C 介面須先指定持久儲存的 LEARNING_DB_PATH，詳見部署說明；未設定時拒絕讀寫 C 紀錄。此版本尚未提供教師下載介面，也不保留每一次編輯的歷程。

介面 C 驗證：27 項 Python 測試、8 項文字範圍斷言通過；本機瀏覽器實測選取／取消、摘要、草稿刷新恢復及提交後刷新。已檢查 1024×768 排版，尚待實體 iPad Safari 觸控驗證。

部署及名冊規格請見 [DEPLOY.md](DEPLOY.md)。2026-09-12 已通過 16 項模擬測試，並以真實服務帳戶讀取指定線上試算表，確認 160 位學生資料有效。以本機 Python HTTP 服務實测 A、B、C 與未分配介面四種狀態的登入、session、錯誤密碼拒絕與登出，全部通過。未修改試算表，未部署 Render，不能以 healthz 成功視為 Google 連線完成。

只提交程式碼至 GitHub。密碼表、private/、work/、JSON 憑證與 .env 不得提交。正式部署後不依賴本機 Excel 或 G 槽。
